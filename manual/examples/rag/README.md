# RAG Examples (`manual/examples/rag/`)

本目錄包含 `Auraflux-Core` 框架中檢索增強生成（Retrieval-Augmented Generation, RAG）與相關 Orchestrator 模組的實作範例。

## 📁 目錄結構與範例列表

1. [`orchestrator-keywords-example.md`](./orchestrator-keywords-example.md)
   - **關鍵字提取範例**：介紹如何使用 `KeywordsExtractor` 針對查詢內容進行智慧關鍵字提取，優化後續檢索精確度。
2. [`rag-orchestrator-example.md`](./rag-orchestrator-example.md)
   - **RAG Orchestrator 範例**：展示如何串接 RAG 檢索器、三元組處理工具（Triple Processor Tool）與大模型客戶端，建構端到端的 RAG 協調流程。
